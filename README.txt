堅気屋 手本引き for Mac

「手本引き.html」をダブルクリックするとSafariまたはChromeで起動します。
インターネット接続は不要です。

遊び方
0. 親を「麗子」「鬼塚」「玄斎」から選びます。親ごとに出目の癖と難易度が異なります。麗子も順目・連続・反対目・ランダムを混ぜるため、単純な繰り返しではありません。
1. BETまたはMAX BETで掛け金を決めます。
2. 1点〜4点の張り方を選び、「親 入りました」を押します。
3. 大・中・止・角の順に、必要な枚数の札を選びます。
4. 「この張りで勝負」を押すと親の手本を公開します。
5. 当たった札の位置に応じて配当が変わります。

代表的な張り方
- 1点 スイチ：大4.5倍
- 2点 ケッタツ：大3.5倍、中は種（元返し）
- 3点 クイチ：大1.5倍、中1倍、止0.3倍
- 4点 安張り：大1.2倍、中0.6倍、止0.2倍、角は0.2倍引き

現金・換金機能はありません。ゲーム内クレジット専用です。
